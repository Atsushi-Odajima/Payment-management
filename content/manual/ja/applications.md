# 決済申請一覧

**決済申請** とは、加盟店サイトでユーザーが商品をカートに入れて決済方法を選択した時点で生成される取引レコードです（Stripe の PaymentIntent、GMO の取引登録に相当）。この画面は **決済完了前の取引を追跡し、入金を消込む** ためのものです。

決済申請と決済一覧は同じ取引テーブルをステータスで分けたものです。

| 画面 | 表示されるステータス |
|---|---|
| 決済申請一覧 | 申請中 / 振込待ち / 与信済 / 失敗 / 期限切れ / キャンセル |
| 決済一覧 | 完了 / 一部返金 / 返金済 |

## 取引の項目

| 項目 | 説明 |
|---|---|
| 取引ID | システムが発行する一意の ID（通知の `payment_id`） |
| 注文番号 | 加盟店側の注文番号 |
| 加盟店 | 取引が発生した加盟店サイト |
| 商品名 / 金額 | カートの内容と請求額（円） |
| ユーザー名 / ユーザーID | 加盟店側のユーザー情報 |
| 決済種別 | クレジット / QR / コンビニ / 銀行振込 / その他 |
| 申請日時 / 完了日時 | 取引の生成時刻と完了時刻 |
| ステータス | 下記ライフサイクル |

銀行振込の取引には **振込ID**（加盟店ごとに 7 桁または 8 桁、一意）、**振込期限**（申請から 7 日後）、**入金額（累計）**、**過不足フラグ**（不足 / 超過）が加わります。

## ステータスのライフサイクル

| ステータス | 意味 | 次に進める操作 |
|---|---|---|
| 申請中 | 生成直後（コンビニなど支払い待ち） | 完了 / 失敗 / キャンセル / 期限切れ |
| 振込待ち | 銀行振込。振込IDを発行し入金を待っている | 入金消込 / キャンセル / 期限切れ（期限超過時） |
| 与信済 | クレジットの与信が取れている | 完了 / 失敗 / キャンセル |
| 完了 | 決済が成立（決済一覧へ移動） | 返金 |
| 失敗 / 期限切れ / キャンセル | 終了状態 | なし |
| 返金済 | 全額返金済み（決済一覧） | なし |

すべての状態変更は、変更前後のステータス・実行者（管理画面 / Webhook / 入金通知（銀行） / 初期データ）・日時とともに **ステータス変更履歴** に記録されます。

## 一覧の並びと絞り込み

- **振込待ち** の取引は振込期限が近い順に上へ表示されます。**期限超過** は行と期限を赤で強調し、「期限超過」バッジを付けます。それ以外は申請日時の新しい順です。
- 決済種別・ステータス・加盟店・申請日の期間（開始 / 終了）で絞り込めます。テスト / 本番はヘッダーのスイッチで切り替えます。

## 操作（マスター権限）

詳細画面の操作はマスター権限のアカウントでログインしている必要があります。一般権限では閲覧のみです。判定はサーバー側で行われます。

| 決済種別 | ボタン | 動作 |
|---|---|---|
| 銀行振込 | 入金消込 | 入金額を入力。**一致** → 完了、**不足** → 振込待ちのまま「不足」フラグ（次の入金で累計）、**超過** → 完了 + 「超過」フラグ |
| 銀行振込 | 期限切れにする | 振込期限を過ぎた振込待ちのみ |
| クレジット等 | 完了にする / 失敗にする | デモ用の手動遷移（本番では PSP からの通知が行う） |
| 共通 | キャンセル | 申請中 / 振込待ち / 与信済のみ |

## 入金通知 API（デモ）

銀行からの入金通知を模した API です。振込IDと入金額を送ると、上と同じ消込ルールが実行され、履歴には実行者「入金通知（銀行）」として記録されます。

```
POST /api/demo/deposit-notify
Authorization: Bearer <DEPOSIT_NOTIFY_SECRET>
Content-Type: application/json

{ "transferId": "48213907", "amount": 24800 }
```

| 項目 | 説明 |
|---|---|
| `transferId` | 振込ID（7 桁または 8 桁の数字） |
| `amount` | 入金額（円、整数） |

応答例:

```
{ "ok": true, "data": { "transferId": "48213907", "paymentId": "pay_…", "amount": 24800,
  "received": 24800, "depositAmount": 24800, "depositDiff": null, "status": "captured", "completed": true } }
```

| 状況 | 応答 |
|---|---|
| 振込IDが存在しない | 404 `transfer_not_found` |
| 振込待ち以外（完了済み・期限切れなど） | 409 `invalid_transition` |
| 不足入金 | 200、`status: "awaiting_transfer"`, `depositDiff: "short"` |
| 超過入金 | 200、`status: "captured"`, `depositDiff: "excess"` |

環境変数 `DEPOSIT_NOTIFY_SECRET` を設定すると Bearer 認証が必須になります。未設定の場合、本番環境では 404、開発環境では認証なしで利用できます。curl の例:

```
curl -X POST http://localhost:3000/api/demo/deposit-notify \
  -H "Content-Type: application/json" \
  -d '{"transferId":"48213907","amount":24800}'
```
