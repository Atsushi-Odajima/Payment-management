# IP 制限管理

管理画面と加盟店 API への接続を許可する **IP アドレスの許可リスト** を管理します。

## 対象

| 対象 | 意味 |
|---|---|
| 管理画面 | この管理画面へのアクセス元 |
| 加盟店API | 特定の加盟店が API を呼び出すサーバーのアクセス元。加盟店の指定が必須 |

## ルールの書き方

- 単一の IPv4 アドレス: `203.0.113.10`
- CIDR 表記: `198.51.100.0/24`（`/0`〜`/32`）

ホスト部のビットは保存時に正規化されます（`198.51.100.77/24` → `198.51.100.0/24`）。IPv6 は現在サポートしていません。

## 現在の接続元 IP と判定

一覧上部に **現在の接続元 IP** と、有効な「管理画面」ルールに対する判定を表示します。

| 判定 | 意味 |
|---|---|
| 許可リストに含まれています | いずれかの有効ルールに一致（一致したルールを表示） |
| 許可リストに含まれていません | 一致するルールがない |
| 有効な管理画面ルールがありません | ルール未設定のため全て許可 |
| IPv6 のため判定対象外 | 接続元が IPv6 |

デモでは判定の表示のみで、実際にアクセスを遮断することはありません。本番では middleware でこの判定を使って 403 を返す実装を追加します。

## 追加・編集・削除

- **＋ ルール追加** からフォームを開き、対象・（加盟店）・IP / CIDR・ラベル・有効/無効を入力します。入力中に正規化後の値が表示されます。
- 一覧の **編集** でフォームを開き、**削除** は確認ダイアログの後に削除されます。
