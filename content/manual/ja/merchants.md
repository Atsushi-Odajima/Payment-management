# 加盟店管理

加盟店（EC サイト運営者）のアカウントを発行・管理します。

## 一覧

加盟店 ID・サイト名・会社名・担当者名・担当代理店・メール通知設定・登録日を表示します。行をクリックすると詳細画面へ移動します。20 件ごとにページ送りされます。

## 加盟店の追加

右上の **＋ 加盟店追加** から登録します。

| 項目 | 説明 |
|---|---|
| 加盟店 ID | `MER-00001` 形式で自動採番。変更できません |
| 加盟店パスワード | 登録時に自動生成され、暗号化して保存されます。画面では常に `********` |
| サイト名 / ふりがな | ふりがなは **全角カタカナのみ** |
| 会社名 / 担当者名 | 必須 |
| 担当代理店 | 任意。代理店管理に登録済みの代理店から選択 |
| メールアドレス / 明細送付先 | 形式を検証。「メールアドレスと同じ」で複製できます |
| システム通知先 URL | 決済結果を送る加盟店側エンドポイント。**https のみ** |
| 通知パラメータ設定 | 通知の型 / 送信パラメータセット / 決済識別子の形式（詳細は「通知パラメータ仕様」） |
| メール通知設定 | 決済ごと / 1 日まとめて通知 / メール通知無し |

必須項目が揃うまで「登録する」は押せません。エラーがある場合は該当項目の下にメッセージが表示され、最初のエラー項目までスクロールします。

## 詳細と編集

詳細画面は **閲覧モード** で開きます。右上の **編集** を押すと編集モードになり、最下部の **更新** で保存します。保存後は自動で閲覧モードに戻ります。

- 加盟店 ID とパスワードは編集できません。
- **パスワードの表示（目のアイコン）と再発行** はマスター権限のみ使えます。一般権限ではボタンが無効になり、API も 403 を返します。
- 再発行すると旧パスワードは無効になります。表示された新しい値を加盟店に連携してください。

## 利用可能な決済手段

「利用可能な決済手段」と「振込IDの桁数」は加盟店フォームの **決済設定** で編集します。振込IDの桁数（7 桁または 8 桁）は、この加盟店の銀行振込の取引に発行される振込IDの長さです。
