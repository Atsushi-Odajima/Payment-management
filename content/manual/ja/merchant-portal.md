# 加盟店管理画面

加盟店が自社の取引や精算を確認するための画面（`/merchant`）です。**管理者（PSP）のセッションとは完全に別**のログイン・Cookie（`wirepay.merchant`）で動き、加盟店は自社のデータしか見えません。

## ログイン

- URL: `/merchant/login`。加盟店ID（`MER-00001`）と、加盟店登録時に発行したパスワード（加盟店詳細でマスター権限が表示 / 再発行できるもの）でログインします
- **5 回連続で失敗すると 15 分間ロック**されます（423）。ロックと成功したログインは操作ログに `merchant.lockout` / `merchant.login` として記録されます（操作者は「加盟店」）
- セッションは 12 時間。ログイン画面は管理者ログインと同じレート制限（10 回 / 分 / IP）です
- デモでは `DEMO_LOGIN_HINT` を設定するとログイン画面に seed の加盟店とパスワードが表示されます

## メニュー

| 画面 | 内容 |
|---|---|
| ホーム | 本日の完了取引・支払待ち・審査中の返金・失敗した Webhook・次回振込予定、最近の取引、お知らせ |
| 取引 | 自社の取引一覧と詳細（内部メモは表示しません）。詳細から **返金申請** ができ、管理画面の返金管理に「申請中」として届きます |
| 返金申請 | 申請と審査結果（否認理由も表示） |
| Webhook 送信ログ | 通知先への送信記録。失敗分は **再送** できます（操作ログ `webhook.resend`、操作者は加盟店） |
| 精算 | 精算バッチの一覧・内訳・明細。確定以降のバッチは **請求書 PDF（インボイス）** を出力できます |
| API キー | 発行済みキーの一覧。**テストキーは自分でローテーション** できます（本番キーは表示のみ、PSP に依頼） |
| 決済手段の状態 | 契約で有効な手段と、全体 / 加盟店単位の停止状況・理由・再開予定 |
| お知らせ | 公開中のお知らせ・メンテナンス・障害情報（対象加盟店の絞り込み込み） |
| サンドボックス | テストキーで実際の公開 API を呼び出すコンソール |

ヘッダーのテスト / 本番スイッチで表示する環境を切り替えます（管理画面と同じ Cookie `wirepay.mode`）。

## 実装メモ（運用担当向け）

- 加盟店側 API は `/api/merchant-portal/*`。middleware は管理者セッションではなく加盟店 Cookie を検証し、CSRF ルールは管理画面と同じです
- 加盟店が行った操作（返金申請・再送・キーのローテーション・請求書出力）は操作ログに **操作者種別「加盟店」** と加盟店IDで残ります
- 加盟店のパスワードを再発行すると、その時点から新しいパスワードでのみログインできます（既存セッションは期限まで有効）
