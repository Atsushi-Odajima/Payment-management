# 代理店手数料

代理店が紹介した加盟店の **精算バッチの振込額** に、代理店ごとの **手数料率** を掛けた月次の支払額を集計します。専用のテーブルは持たず、精算バッチを元帳としてその都度計算します。

## 計算方法

- 対象は加盟店の **担当代理店** が設定されている精算バッチのうち、ステータスが **確定 / 振込予定 / 振込済** のもの。集計中・保留のバッチは確定するまで含まれません。
- 対象月は **精算期間の開始日**（日本時間）で決まります。
- 手数料 = 振込額（純額）× 手数料率（%）、円未満切り捨て。振込額がマイナスのバッチは 0 円です。
- 手数料率は代理店の現在の設定を使います（変更すると過去の月の表示も変わります。確定額を保存したい場合は CSV を保管してください）。
- ヘッダーのテスト / 本番スイッチのモードの精算だけが対象です。

## 画面

- **対象月** と **代理店** で絞り込み、代理店ごとの合計（振込額・手数料・加盟店数・精算数）を表示します。**内訳を表示** で加盟店 / 精算バッチごとの明細が開き、精算詳細へ移動できます。
- **CSV 出力** は明細行（代理店・加盟店・精算期間・ステータス・振込額・手数料率・手数料）を出力します。
- 代理店詳細にも当月の手数料サマリーが表示されます。

## 権限

| 操作 | マスター | 一般 |
|---|---|---|
| 閲覧・CSV | ○ | ○ |

集計のみで更新操作はないため、操作ログには記録されません。代理店の手数料率の変更は `agent.update` として記録されます。
