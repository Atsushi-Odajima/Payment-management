# お知らせ配信

加盟店向けの **お知らせ・メンテナンス・障害情報** を作成・公開します。

## 種別と表示

| 種別 | 表示 |
|---|---|
| お知らせ | お知らせ一覧と加盟店 API のみ（ベルにはピン留めされません） |
| メンテナンス | ヘッダーの通知ベルの先頭に **ピン留め**（黄色のバッジ） |
| 障害 | 通知ベルの先頭に **ピン留め**（赤色のバッジ）。更新履歴（発生 → 対応中 → 復旧）を時系列で表示 |

公開中（ステータスが「公開」で公開期間内）のものだけが表示されます。加盟店は自分の API キーで `GET /api/merchant-api/announcements` を呼ぶと、自分が対象のお知らせ（全加盟店向け + 自分を指定したもの）を取得できます。

## 作成と公開

1. **＋ お知らせを作成** で種別・タイトル・本文・公開日時・公開終了日時（空欄なら終了するまで）・対象（全加盟店 / 特定の加盟店）を入力します。
2. **下書きとして保存** か **公開する** を選びます。下書きは詳細画面の **公開する** でいつでも公開でき、公開中のものは **終了する** で止められます。終了したものは再公開できます。
3. 障害は本文が「発生」の最初の更新として記録されます。詳細画面の **更新を追加** で「対応中」「復旧」の経過を追記すると、ピン留めに最新の状況が表示されます。

作成・編集・公開・終了・更新の追加はすべて操作ログに記録されます。
