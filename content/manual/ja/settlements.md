# 精算管理

加盟店ごとに、対象期間の売上から手数料・返金・チャージバック・振込手数料を差し引いた **差引支払額** を精算バッチとして管理します。

## 精算設定（加盟店詳細の「精算設定」タブ）

| 項目 | 説明 |
|---|---|
| 締めサイクル | 月末締め / 15日・月末締め / 週次締め。精算バッチの既定の対象期間になります |
| 支払サイト | 翌月末 / 翌月15日 / 翌々月15日 / 翌週。対象期間の終了日から振込予定日を計算します |
| 振込先口座 | 銀行名・支店名・口座種別（普通 / 当座）・口座番号（7〜8 桁）・口座名義。デモではダミーで構いません |
| 精算手数料 | 振込 1 回ごとに差し引く手数料（円） |

変更は操作ログに記録されます。

## 精算バッチの生成

精算管理の上部フォームで加盟店と対象期間を指定して **生成する** を押すと、期間内に **完了した取引**（手数料は各取引の完了時点で適用中の契約料率で計算）、**完了した返金**、**確定したチャージバック** を集計し、明細行付きのバッチを作ります。既定の期間は加盟店の締めサイクルの直近の締め分です。同じ加盟店・期間・モードのバッチは 1 つだけ作れます。

- 本来は締めサイクルごとに自動で走る処理ですが、デモでは手動で生成します。
- ヘッダーの **テスト / 本番** スイッチで対象データが切り替わります。本番運用ではテストモードの取引を精算に含めません（テストのバッチはデモ用です）。

## ステータスと操作（マスター権限）

| ステータス | 意味 | 可能な操作 |
|---|---|---|
| 集計中 | 生成直後。明細を確認する段階 | 確定する / バッチを破棄 |
| 確定 | 金額が確定し、明細は変更不可 | 振込予定にする / 保留する |
| 振込予定 | 振込予定日に支払う予定 | 振込済にする / 保留する |
| 振込済 | 支払完了 | — |
| 保留 | チャージバック係争中などで支払を止めている（理由必須） | 保留を解除（確定に戻る） |

すべての操作は状態遷移表に従い、操作ログに記録されます。

## 詳細と明細 CSV

バッチ詳細には内訳（売上総額・手数料合計・返金合計・チャージバック合計・精算手数料・差引支払額）と明細行（発生日時・種別・注文番号・決済手段・金額・手数料）を表示します。**明細 CSV** で明細行を、一覧右下の **CSV** でバッチ一覧を出力できます。

## 加盟店側の参照

加盟店は自分の API キー（Bearer）で `GET /api/merchant-api/settlements` を呼ぶと、自分の精算バッチ一覧を、`?id=<バッチID>` を付けると明細付きの 1 件を取得できます。キーのモード（テスト / 本番）と同じモードのバッチだけが返ります。
