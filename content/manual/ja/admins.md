# 管理者・操作ログ・検索

この章では、管理画面を操作する **管理者アカウント**、すべての変更を記録する **操作ログ**、ヘッダーの **横断検索** を説明します。

## ログインと権限

- ログインは **ログインID + パスワード** です。トップページを開くとログイン画面が表示され、ログイン後は 12 時間セッションが維持されます。
- 権限はアカウントに紐づきます（画面上の切り替えはありません）。

| 機能 | マスター | 一般 |
|---|---|---|
| 各画面の閲覧 | ○ | ○ |
| 加盟店 / 代理店 / IP制限の登録・更新 | ○ | ○ |
| 加盟店パスワードの表示・再発行 | ○ | × |
| 取引の完了・失敗・キャンセル・期限切れ・入金消込 | ○ | × |
| 返金 | ○ | ○ |
| 管理者の招待・編集・仮パスワード再発行・二段階認証の解除 | ○ | × |
| 操作ログの閲覧 | ○ | ○ |

## 管理者管理（設定 → 管理者管理、マスターのみ）

- **招待**: ログインID・氏名・メールアドレス・権限を入力すると、初期パスワードが **一度だけ画面に表示** されます（デモではメール送信の代わり）。招待したアカウントは「招待中」で、本人が初回ログインすると「有効」になります。
- **編集**: 氏名・メールアドレス・権限・有効/無効を変更できます。ログインIDは変更できません。自分自身の権限・ステータスは変更できず、**最後の有効なマスター** を無効化・降格することもできません。
- **仮パスワードを再発行**: 対象ユーザーの新しいパスワードを発行し、一度だけ表示します。
- **二段階認証を解除**: 端末を紛失したユーザーの二段階認証を解除します。本人が再登録できます。

## アカウント設定（右上の氏名 → アカウント設定）

- **パスワード変更**: 現在のパスワードを確認のうえ、8 文字以上の新しいパスワードに変更します。
- **二段階認証（TOTP / RFC 6238）**: 「認証アプリを登録する」で QR コードと手入力用キーが表示されます。Google Authenticator などで読み取り、アプリに表示された 6 桁コードを入力すると有効になります。以降のログインでは、パスワードのあとにコードを求められます（コードの有効期限は 5 分、前後 30 秒のずれを許容）。解除にはパスワードの再入力が必要です。

## 操作ログ（設定 → 操作ログ）

データを変更する操作はすべて記録されます: 誰が（管理者、または Webhook / 入金通知 / Cron などのシステム）、いつ、どの操作を、何に対して、接続元 IP はどこか、そして **変更前 / 変更後** の値です。パスワードや認証情報などの機微な項目は `[redacted]` として記録されます。

- 一覧は操作者・操作種別・対象種別・期間で絞り込め、列見出しで並べ替え、**CSV 出力** できます。
- 行をクリックすると詳細が開き、変更前後の値が項目ごとに並び、変わった項目が強調表示されます。

記録される操作: ログイン / ログアウト、パスワード変更、二段階認証の有効化・解除、管理者の招待・更新・仮パスワード再発行、加盟店の登録・更新・パスワード再発行、代理店の登録・更新、取引の作成・完了・キャンセル・返金・失敗・期限切れ・入金消込、プロバイダの接続・更新・削除、IP ルールの追加・更新・削除、デモデータ初期化。

## 横断検索

ヘッダーの検索ボックス（**Ctrl+K / Cmd+K** でフォーカス）に 2 文字以上入力すると、取引（取引ID・注文番号・振込ID・ユーザーID・メールアドレス・ユーザー名）、加盟店（加盟店ID・サイト名・会社名・メール）、代理店（代理店ID・名称・会社名・メール）、管理者（マスターのみ）をまとめて検索し、カテゴリ別に表示します。Enter ですべての結果を一覧するページに移動します。
