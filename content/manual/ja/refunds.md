# 返金管理

完了した取引の **返金申請** を審査し、返金履歴を管理します。返金は「申請 → 承認 / 否認」の 2 段階で、申請は一般権限でも行えますが、承認と否認は **マスター権限** のみです。

## 返金の申請（取引詳細）

[決済一覧](/manual/payments) の取引詳細で **返金申請** を押し、次を入力します。

| 項目 | 説明 |
|---|---|
| 返金額 | 返金可能残額（取引額 − 返金済額 − 審査待ちの申請額）の範囲で指定します。全額なら「全額」、それ以外は「一部」として記録されます |
| 返金理由 | 顧客都合 / 商品不良 / 重複決済 / その他（その他は詳細が必須） |
| 理由（詳細） | 任意の補足。期限超過の強制返金では必須です |

- 対象は **完了 / 一部返金** の取引のみです。
- 加盟店ごとの **返金可能期限**（完了日 + 加盟店設定の日数）を過ぎた取引は申請できません。マスター管理者のみ「強制返金」にチェックを入れ理由を記入すると申請でき、一覧と詳細に「期限超過（強制）」と表示されます。
- 審査待ちの申請額は返金可能残額から差し引かれるため、累計で取引額を超える申請は登録できません。

## 審査（マスター）

返金管理一覧では **申請中** の返金が上に表示されます。詳細画面の **承認する** で返金が確定し、取引のステータスが **一部返金** または **返金済** に更新されます（デモでは処理中を経ず即時完了）。**否認する** は申請を却下し、審査メモを残せます。承認・否認とも [操作ログ](/manual/admins) に記録されます。

## 一覧の絞り込みと CSV

ステータス（申請中 / 承認 / 否認 / 処理中 / 完了 / 失敗）・加盟店・申請日の期間で絞り込めます。ヘッダーの **テスト / 本番** スイッチで対象データが切り替わります。右下の **CSV** で表示中の条件の返金を出力できます。

## 取消（キャンセル）との違い

与信済で売上確定前の取引を取りやめる場合は返金ではなく、取引詳細の **キャンセル** を使います（申請中 / 振込待ち / 与信済の取引が対象、マスター権限）。返金は完了した取引の代金を戻す操作です。
