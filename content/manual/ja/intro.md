# はじめに

Wire Pay は、決済代行（PSP）の運用担当者が **加盟店・代理店・決済・申請・アクセス制限** を一つの管理画面で扱うためのダッシュボードです。このマニュアルは管理画面の各機能の使い方と、加盟店へ送信する通知の仕様をまとめています。

## デモモードについて

このデモは外部の決済 API を呼び出しません。

- **接続テスト** は入力された認証情報の形式だけを検証します。
- **決済の作成・売上確定・取消・返金** は DB 上の状態を更新するだけで、実際の資金移動は発生しません。
- **通知（Webhook）** は送信されません。加盟店詳細・追加画面で「送信されるリクエストのサンプル」を確認できます。
- **IP 制限** は実際のアクセス制御を行わず、現在の接続元 IP に対する判定結果のみ表示します。
- デモデータは毎日初期化されます。追加・編集した内容は翌日には消える場合があります。

## 権限（マスター / 一般）

画面右上の **権限トグル** でデモ用の権限を切り替えられます。

| 操作 | マスター | 一般 |
|---|---|---|
| 各画面の閲覧 | ○ | ○ |
| 加盟店・代理店・IP ルールの追加・編集 | ○ | ○ |
| 加盟店パスワードの表示・再発行 | ○ | × |
| 決済申請の承認・否認・差戻し | ○ | × |

権限の判定はサーバー側（API）で行われます。一般権限で表示だけを切り替えてもパスワード取得や申請の審査はできません。本番環境ではこのトグルはログインユーザーのロールに置き換わります。

## ログイン

`ADMIN_PASSWORD` が設定された環境では、閲覧は誰でも可能ですが **作成・更新・削除にはログイン** が必要です。右上の「ログイン」からパスワードを入力してください。

## 言語

右上の **EN / 日本語** トグルで表示言語を切り替えられます。選択は保存され、次回アクセス時も維持されます。金額は言語に関わらず日本円（¥）、日時は日本時間（Asia/Tokyo）で表示します。
