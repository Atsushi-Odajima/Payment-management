# はじめに

Wire Pay は、決済代行（PSP）の運用担当者が **加盟店・代理店・取引（決済申請 / 決済）・返金・精算・Webhook・リスク対策・レポート・通知・定期課金・決済リンク** を一つの管理画面で扱うためのダッシュボードです。このマニュアルは各機能の使い方と、加盟店向けの通知・API 仕様をまとめています。

## デモモードについて

このデモは外部の決済 API を呼び出しません。

- **接続テスト** は入力された認証情報の形式だけを検証します。
- **決済の作成・完了・取消・返金・入金消込・定期課金の課金** は DB 上の状態を更新するだけで、実際の資金移動は発生しません。定期課金の課金はデモ用の失敗率で失敗します。
- **Webhook（加盟店への通知）は実際に送信されます**。seed の加盟店の通知先はデモ用の受信エンドポイントです（[Webhook 送信ログ](/manual/webhooks)）。
- **メール** は送信せず、送信ログに「デモ（未送信）」として記録します（`EMAIL_PROVIDER` で差し替え可能）。
- **IP 制限** のブロックルールは実際に適用されます（画面は遮断画面、API は 403）。自分の接続元をブロックするルールは保存できません。
- デモデータは毎日初期化されます。追加・編集した内容は翌日には消える場合があります。

## ログインと言語

トップページを開くとログイン画面が表示され、**ログインID とパスワード**（二段階認証を有効にしている場合は認証アプリのコードも）でログインします。ログイン後は 12 時間セッションが維持されます。各画面の閲覧は公開ですが、**作成・更新・削除にはログイン** が必要です。右上の氏名から「アカウント設定」を開けます。

右上の **EN / 日本語** トグルで表示言語を切り替えられます。選択は保存され、次回アクセス時も維持されます。金額は言語に関わらず日本円（¥）、日時は日本時間（Asia/Tokyo）で表示します。ヘッダーの **テスト / 本番** スイッチは一覧・ダッシュボード・レポートが参照するデータのモードを切り替えます。
