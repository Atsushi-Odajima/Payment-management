# 代理店管理

加盟店を紹介・取次する代理店を管理します。

## 一覧

代理店 ID・代理店名・会社名・担当者名・手数料率・紐付く加盟店数・ステータス・登録日を表示します。行をクリックすると詳細へ移動します。

## 代理店の追加

| 項目 | 説明 |
|---|---|
| 代理店 ID | `AGT-00001` 形式で自動採番。変更できません |
| 代理店名 / ふりがな | ふりがなは全角カタカナのみ |
| 会社名 / 担当者名 / メールアドレス | 必須。メールは形式を検証 |
| 手数料率 | 0〜100 の範囲、小数第 2 位まで（例: `3.5`） |

## 詳細と編集

加盟店と同じく **閲覧モードで開き、右上の「編集」→ 最下部の「更新」** で保存します。編集モードではステータス（有効 / 無効）を切り替えられます。

## 紐付く加盟店

詳細画面の下部に、この代理店を「担当代理店」に設定している加盟店の一覧が表示されます。加盟店側の担当代理店は、加盟店の追加・編集フォームの「担当代理店」プルダウンで設定します。

- 無効にした代理店は、新規の加盟店フォームでは選択肢に出ません（既に紐付いている加盟店の編集では引き続き表示されます）。
