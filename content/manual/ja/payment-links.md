# 決済リンク

商品名と金額を固定した **決済ページの URL / QR コード** を発行し、加盟店サイトを介さずに決済を受け付けます。SNS やメールでの販売、店頭での QR 提示に使えます。

## 発行

**＋ リンクを発行** で次を入力します。

| 項目 | 説明 |
|---|---|
| 加盟店 | 売上の帰属先。決済ページで選べる支払方法は加盟店の「利用可能な決済手段」のうち、同じモードで有効なプロバイダがあるものです |
| 商品名 / 金額 / 説明 | 決済ページに表示されます。発行後は変更できません（無効化して再発行してください） |
| 有効期限 | 指定日の終わり（日本時間）まで。空欄なら無期限 |
| 最大利用回数 | 取引が作成された回数の上限。空欄または 0 で無制限 |

発行するとヘッダーのテスト / 本番スイッチのモードでリンクが作られ、詳細画面に **URL**（コピー可）と **QR コード** が表示されます。

## 決済ページ（`/pay/<トークン>`）

- ログイン不要の公開ページです。管理画面のナビは表示されません。
- 顧客が支払方法と氏名（メールアドレスは任意）を入力して **支払う** を押すと、取引が **与信済** で作成され、リンクの利用回数が +1 されます。
- **銀行振込** を選ぶと振込 ID と振込期限が表示され、取引は **振込待ち** になります。入金消込は決済申請一覧から通常どおり行います。
- それ以外の支払方法ではデモ用の **お支払いを確定する** ボタンが表示され、押すと取引が **完了** になります（実際のカード入力はありません）。
- 無効化済み・期限切れ・上限到達のリンクはその旨を表示し、決済できません。

作成された取引は注文番号 `LNK-<トークン先頭 6 文字>-<連番>` で、取引詳細に「決済リンク」として表示されます。

## 無効化

詳細画面の **リンクを無効化** で以降の利用を止めます。作成済みの取引には影響しません。無効化は取り消せないため、再開したい場合は新しいリンクを発行してください。

## 権限

| 操作 | マスター | 一般 |
|---|---|---|
| 閲覧 | ○ | ○ |
| 発行・無効化 | ○ | ○ |

発行と無効化は操作ログ（`payment_link.create` / `payment_link.disable`）に記録されます。決済ページからの取引作成は actor「システム」で記録されます。
