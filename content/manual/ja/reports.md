# 集計レポート

期間・加盟店・決済種別で絞り込んだ決済の指標と推移を表示し、CSV に出力します。ヘッダーの **テスト / 本番** スイッチで対象データが切り替わります。

## 絞り込み

| 項目 | 説明 |
|---|---|
| 集計単位 | **日次**（既定: 直近 30 日を日ごとに）/ **月次**（今年を月ごとに）/ **任意期間**（開始日〜終了日を日ごとに） |
| 開始日 / 終了日 | 申請日（取引の作成日）で絞り込みます |
| 加盟店 / 決済種別 | 任意 |

## 指標

| 指標 | 計算 |
|---|---|
| 決済申請数 | 期間内に作成された取引の件数 |
| 完了件数 / 完了金額 | 完了・一部返金・返金済・チャージバックになった取引（一度完了した取引） |
| 成功率 | 完了件数 ÷ 決済申請数 |
| 離脱率 | 期限切れ・キャンセルになった件数 ÷ 決済申請数 |
| 平均決済額 | 完了金額 ÷ 完了件数 |
| 返金率 | 返金済額 ÷ 完了金額 |
| チャージバック率 | 期間内に発生したチャージバック件数 ÷ 完了件数 |

## グラフ

- **推移**（折れ線）: 集計単位ごとの完了金額。下の表に申請数・完了件数・完了金額を併記します。
- **決済種別の比率**（円）: 完了金額の決済種別別シェア。
- **加盟店別ランキング**（棒）: 完了金額の上位 10 加盟店。

## CSV

- **集計 CSV**: 集計単位ごとの行（期間・申請数・完了件数・完了金額）。
- **明細 CSV**: 期間内の取引 1 件 1 行（申請日時・取引ID・注文番号・加盟店・決済種別・ステータス・金額・返金済額）。上限は 10,000 行です。
