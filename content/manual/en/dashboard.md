# Dashboard

The home page shows six cards, one per management area. Each card displays a **key figure** and links to the corresponding screen.

| Card | Figure | Destination |
|---|---|---|
| Merchants | Number of merchants | Merchant list |
| Agents | Number of agents | Agent list |
| Payments | Today's payment count and amount (captured sales) | Payment list |
| Payment Applications | Pending count (highlighted with a badge when > 0) | Applications |
| IP Restrictions | Enabled rules | IP restrictions |
| Admin Manual | Number of chapters | This manual |

## What “today” means

Today's payments are counted from **00:00 Japan time (Asia/Tokyo)**, independent of where the server runs.

## Header buttons

- **+ Add Payment Provider** — connect Stripe, PayPay and others (Settings → Payment providers).
- **+ Create Payment** — create a demo payment through a connected provider.

## Navigation

The sidebar lists the same six features as the cards. On phones, the bottom tab bar gives access to the main screens.
