# テストカード番号

テスト環境（`wp_test_ak_` キー）では、`card.number` に下表の番号を送ると **シナリオ別の結果** を再現できます。表にない Luhn 有効な番号は成功として扱います。本番環境でこれらの番号を送ると 400 `test_card_in_live` です。

- 有効期限は未来の月であれば任意です（例: `expMonth: 12, expYear: 2028`）
- `cvc` は検証にのみ使い、保存しません。保存するのはカードブランドと下 4 桁、および不正検知用のハッシュだけです
- 失敗シナリオの取引は `status: "failed"` と `failureReason`（下表の結果）で記録され、加盟店管理画面にも表示されます
- 「与信済で止まる」シナリオは `status: "authorized"` で返り、Wire Pay の管理画面から完了（キャプチャ）できます

## コンビニ・銀行振込のテスト

- コンビニ: 作成後に `konbini.receiptNo` が返ります。テスト環境では Wire Pay の管理画面（取引詳細の入金消込）またはデモの入金通知 API で支払い済みにできます
- 銀行振込: `bankTransfer.transferId` が返ります。同様に入金消込で完了します
