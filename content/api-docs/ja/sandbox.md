# サンドボックス

[加盟店管理画面 → サンドボックス](/merchant/sandbox) では、テスト用 API キーで **実際の公開 API（`/api/v1`）** を呼び出せます。専用のモック環境ではなく本番と同じコードパスなので、ここで通ったリクエストはそのまま本番キーでも使えます。

## 使い方

1. 加盟店管理画面にログインし、「API キー」でテストキー（`wp_test_ak_…`）を確認します（無い場合は Wire Pay に発行を依頼してください）
2. 「サンドボックス」でキーを貼り付け、エンドポイントを選びます。リクエストボディにはサンプルを読み込めます
3. 「送信」でブラウザから API を呼び出し、HTTP ステータス・所要時間・レスポンスを確認します。同じリクエストの curl コマンドも表示されます

## 注意

- キーはこのブラウザの **sessionStorage** にのみ保存され、サーバーには送りません（API 呼び出しの Authorization ヘッダーを除く）
- 本番キー（`wp_live_ak_`）は拒否されます
- サンドボックスで作った取引もテスト環境の実データとして加盟店管理画面・Wire Pay の管理画面に表示され、Webhook も実際に送信されます
- レート制限（60 リクエスト / 分）はサンドボックスにも適用されます
